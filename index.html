Mi Primer Proyecto Publicado

Sitio vinculado y subido mediante la terminal de comandos, listo para verse en GitHub Pages.

📁 Estructura del Proyecto

Este sitio utiliza tres archivos separados:

  • index.html (Estructura)
  • styles.css (Diseño)
  • script.js (Animación y Lógica)

💻 pasos a seguir (Git)

  1. git init
  2. git add .
  3. git commit -m "..."
  4. git push -u origin main

⚠️ Advertencia Técnica

Prohibido usar la interfaz web para "arrastrar y soltar" archivos. El dominio de la terminal es clave para garantizar la trazabilidad e integridad histórica del proyecto.
